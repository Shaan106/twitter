## Read at the start of every session

1. `state.json` for account identity, publication mode, and schedule.
2. `IDENTITY.md` for the fictional rat persona, then `VOICE.md` for editorial judgment.
3. `OPERATING.md` for the session routine and platform restrictions.
4. `QUEUE.md`, `REPLIES.md`, and the latest file in `logs/` for continuity and duplicate checks.
5. `READING-LIST.md` for the tech/startup source feed and reasons for following.

Keep confirmed public actions separate from drafts and plans. The workspace has unrelated, pre-existing app changes. Stage and commit only files owned by this account project; never use `git add .` or `git commit -a`.
